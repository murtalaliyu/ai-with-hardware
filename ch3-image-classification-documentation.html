Technical Documentation

Reference for the Chapter 3 cats-vs-dogs system: a from-scratch CNN with an interactive CLI (ch3-image-classification.py) and a browser UI PetScope (ch3-image-classification-app.py).

Binary classification Keras / TensorFlow CLI menu loop Flask web UI 128×128 RGB

1. Overview

The project trains and serves a from-scratch convolutional neural network that classifies images as cat or dog. Weights are saved to best_model.keras and reused by both the CLI and the web app.

From-scratch means the network is defined layer-by-layer and trained from randomly initialized weights on the project dataset only — not a pretrained backbone such as MobileNet or ResNet.

Two entry points
  • ch3-image-classification.py — train, load, upload via file dialog, evaluate test set (menu loop)
  • ch3-image-classification-app.py — PetScope web UI for drag-and-drop prediction in the browser

3. CLI Menu

ch3-image-classification.py runs in an infinite menu loop until Quit. The in-memory model persists across choices.

Startup

If best_model.keras exists, the script asks whether to load it immediately ([Y/n]) so you can jump to uploads without retraining.

Menu options

OptionActionRequires model?
1 Retrain from scratch; saves best_model.keras No (creates one)
2 Load existing best_model.keras No (loads one)

4 Evaluate on ch3-dataset/test_set Yes
5 Quit —

4. Web UI (PetScope)

PetScope is a Flask app that loads the same best_model.keras and exposes a branded browser interface for drag-and-drop classification.

Start the server

python ch3-image-classification-app.py
# Open http://127.0.0.1:5000

HTTP API

MethodPathDescription
GET / Serves ch3-image-classification-index.html
GET /api/status Whether the model file exists and is loaded in memory
POST /api/predict Multipart form field image → JSON prediction

Predict response shape

{
  "label": "Dog",
  "confidence": 0.913,
  "dog_probability": 0.913,
  "uncertain": false,
  "filename": "pet.jpg"
}

uncertain is true when confidence is below CONFIDENCE_HINT_THRESHOLD (0.65). The UI shows a note that the binary model always picks cat or dog.

Static assets & Flask paths

Because the app filename contains hyphens, Flask’s default root-path detection can fail to locate static/ and templates/. The app sets them explicitly from __file__: 

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
app = Flask(
    __name__,
    static_folder=os.path.join(BASE_DIR, 'static'),
    template_folder=os.path.join(BASE_DIR, 'templates'),
)

Template references:

  • css/ch3-image-classification-style.css
  • js/ch3-image-classification-app.js
After renaming static files, restart the Flask process and hard-refresh the browser (Ctrl+F5). An old process may still serve cached HTML pointing at obsolete paths like style.css.

UI behavior

Open PetScope; status shows model ready / missing
Drag & drop or browse to select an image
Click Classify → POST /api/predict
See label, confidence meter, optional uncertain note

8. Model Architecture

Built in build_model() (CLI) as a Keras Sequential stack.

StageLayersRole
Block 1 Conv2D(32) → BatchNorm → MaxPool2D Low-level features
Block 2 Conv2D(64) → … → Dropout(0.25) Mid-level patterns
Block 3 Conv2D(128) → … → Dropout(0.25) Higher-level parts
Block 4 Conv2D(256) → … → Dropout(0.25) Richest feature maps
Head Flatten → Dense(256) → Dropout(0.5) → Dense(1, sigmoid) P(dog) ∈ [0, 1]
  • Adam with learning_rate=0.0005
  • Loss: binary_crossentropy
  • Metric: accuracy

9. Data Pipeline

Training uses ImageDataGenerator with augmentation (rotation, shift, shear, zoom, horizontal flip). Validation, test, CLI uploads, and web uploads use rescale-only preprocessing to IMG_SIZE and [0, 1] pixels.

10. Training

CLI option 1 → train_model(): up to 40 epochs with callbacks; EarlyStopping usually finishes sooner. Returns the model to the menu loop.

11. Callbacks

CallbackKey settingsBehavior
EarlyStopping val_loss, patience 8, restore best weights Stop when validation loss plateaus
ModelCheckpoint val_accuracy, save_best_only Write best_model.keras
ReduceLROnPlateau factor 0.5, patience 3 Halve LR when val loss stalls

12. Loading a Saved Model

CLI option 2 and PetScope both call Keras load_model on best_model.keras. Missing file → error / 503 until you train via the CLI.

13. CLI Upload & Predict

Option 3 flow:

  1. require_model — must have trained or loaded first
  2. choose_image_file — Tkinter dialog; typed path fallback
  3. predict_single_image — returns (label, confidence)

Sigmoid output is P(dog). If > 0.5 → Dog with confidence = P(dog); else Cat with confidence = 1 − P(dog).

14. Test Evaluation

CLI option 4 → evaluate_test_set(model) on ./ch3-dataset/test_set. Not run automatically; choose it when needed.

15. Binary Classifier Limits

The model only knows two classes. Non-pet images still receive a Cat or Dog label (often with high “confidence”). Confidence means “more like A than B,” not “this is definitely a pet.”

PetScope surfaces an uncertain hint when confidence < 0.65. A proper fix is a third “other” class or out-of-distribution detection — not available in the current binary head.

17. Usage

Train and use the CLI

.\.venv313\Scripts\Activate.ps1
python ch3-image-classification.py
# Choose 1 to train, then 3 to upload images, 4 for test accuracy, 5 to quit

Use the web UI

python ch3-image-classification-app.py
# Browser → http://127.0.0.1:5000

Train at least once with the CLI so best_model.keras exists before relying on PetScope predictions.

18. Expected Performance

With 128×128 inputs, augmentation, BatchNorm, and callback-driven training, validation accuracy in the high 80s (e.g. ~89%) is strong for a from-scratch CNN on this cats/dogs setup. Chance baseline is ~50%. Transfer learning typically reaches the mid–high 90s.

19. Limitations & Notes

  • Always answers cat or dog — no native “neither” class.
  • Class index order depends on folder name sorting in flow_from_directory.
  • CLI option 3 needs a GUI for the file dialog; typed path is the fallback.
  • Hyphenated Flask app filename requires explicit static_folder / template_folder.
  • Restart Flask after renaming templates/static files; hard-refresh the browser.
  • GPU optional; native Windows TF ≥ 2.11 is typically CPU-only.
